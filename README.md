# MQ - 仿 RabbitMQ 实现消息队列

## 1. 项目介绍

本项目仿照 **RabbitMQ** 实现了一个简单的分布式消息队列系统。消息队列是分布式系统中实现生产者-消费者模型的**核心中间件**，主要用于：

- **解耦合**：生产者和消费者无需直接通信
- **异步处理**：提高系统响应速度  
- **流量削峰**：应对突发流量
- **负载均衡**：多个消费者共同处理任务

## 5. 核心功能模块

### 5.1 交换机管理 (Exchange)

- **Direct**：直接交换，精确匹配 routing key
- **Fanout**：广播交换，发送到所有绑定队列  
- **Topic**：主题交换，支持通配符匹配

### 5.2 队列管理 (Queue)

- 消息存储和检索
- 持久化支持
- 自动删除机制

### 5.3 绑定管理 (Binding)

- 交换机和队列的关联关系
- 支持 binding key 路由规则

### 5.4 消息管理 (Message)

- 消息持久化存储
- 文件系统存储消息内容
- 消息确认机制（自动/手动ACK）

### 5.5 路由算法 (Router)

支持 `*` 和 `#` 通配符的复杂模式匹配：

- `*` 匹配一个单词
- `#` 匹配零个或多个单词

### 5.6 网络通信协议

```
+----------+-----------+-------------+-----------+
|  4字节   |   4字节   |  变长字节   |   4字节   |
|  长度    | 类型长度  |  类型名称   |  校验和   |
+----------+-----------+-------------+-----------+
|              Protobuf 序列化数据               |
+-----------------------------------------------+
```

## 6. 核心特性

### 6.1 高性能架构

- **基于 Muduo 的 Reactor 模式**
- **非阻塞 I/O 和事件驱动**
- **线程池处理业务逻辑**

### 6.2 数据可靠性

- **元数据 SQLite 持久化**
- **消息文件系统存储**
- **事务支持保证一致性**

### 6.3 负载均衡

- **多消费者轮询分发**
- **信道级别的资源隔离**

### 6.4 扩展性

- **虚拟主机设计**（支持多租户）
- **模块化架构**，易于扩展
